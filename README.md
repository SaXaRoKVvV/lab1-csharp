### Текст задачи

Дана сигнатура метода: `public int SumLastNums(int x)`. Необходимо реализовать метод таким образом, чтобы он возвращал результат сложения двух последних знаков числа x.

### Алгоритм решения

1. Сначала проверяю, что число минимум двузначное. Если нет — вывожу ошибку.
2. Беру последнюю цифру через `x % 10`.
3. Делю число на 10 (отбрасываю последнюю цифру) и снова беру остаток от деления на 10 — это предпоследняя цифра.
4. Складываю их и возвращаю результат.

### Алгоритм решения
